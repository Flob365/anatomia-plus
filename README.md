# Anatomia+

Atlas anatomique humain interactif en français. L’application couvre 11 organes répartis dans 5 systèmes et permet d’explorer 110 structures avec noms latins, rôle, description anatomique, relations et informations cliniques pédagogiques.

## Lancer le projet

```bash
pnpm install
pnpm dev
```

Le site s’ouvre sur `http://localhost:5173`.

## Vérifier et construire

```bash
pnpm test:run
pnpm build
```

## Interactions

- Sélectionner un système ou un organe depuis le corps ou le rail gauche.
- Cliquer sur les repères ou l’arbre anatomique pour changer de structure.
- Basculer entre `Externe`, `Coupe`, `Réseaux` et `Isoler`.
- Faire glisser l’organe pour simuler sa rotation ; utiliser la molette ou les boutons pour zoomer.
- Rechercher en français ou en latin avec `⌘/Ctrl + K`.
- Partager l’URL pour restaurer l’organe, la structure, le mode et la caméra.

> Le contenu est fourni à des fins pédagogiques et ne remplace pas un avis médical.
